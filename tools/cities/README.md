# قاعدة المدن الأوفلاين

قاعدة مدن مدمجة مع التطبيق لاختيار المدينة يدوياً بدون إنترنت (SPEC §7.1: ~10 آلاف مدينة).

## المصدر والترخيص

- المصدر: [GeoNames](https://www.geonames.org/) — ملف `cities15000.zip` من
  https://download.geonames.org/export/dump/
- الترخيص: **CC BY 4.0** — يلزم الإسناد.

> **واجب:** يجب ذكر GeoNames في شاشة «المصادر والتراخيص» داخل التطبيق قبل النشر
> (مع الروابط وترخيص CC BY 4.0). البند مسجل في TODO المشروع.

## البناء

من مجلد `yousuf/`:

```powershell
python tools/cities/build_cities.py
```

المخرجات: `assets/db/cities.json` — مصفوفة مضغوطة مرتبة تنازلياً بالسكان:

```json
{"id":108410,"ar":"الرياض","en":"Riyadh","cc":"SA","lat":24.71355,"lng":46.72193,"tz":"Asia/Riyadh","pop":7641670}
```

- `ar`: أول اسم عربي في أسماء GeoNames البديلة، وإلا الاسم اللاتيني.
- `tz`: معرّف IANA — يستهلكه حساب المواقيت مباشرة.

## إعادة التوليد

- التغيير الوحيد المطلوب عادةً هو `TOP_N` أو تحديث بيانات GeoNames (احذف
  `.cache/cities15000.zip` ثم أعد التشغيل).
- السكربت يفحص تلقائياً: العدد = 10,000، وجود الرياض/القاهرة/برلين/نيويورك
  بأسماء عربية سليمة، وصحة JSON.
